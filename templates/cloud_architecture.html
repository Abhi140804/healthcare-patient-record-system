Containerization (Docker)

Packages application code, system libraries, and Python dependencies into an immutable container image. This eliminates "works on my machine" bugs and allows identical execution locally and on Google Cloud Run or AWS.

🛡️

Security & Confidentiality

Passwords are never stored in plain text; they are hashed with salted PBKDF2/SHA-256. All database operations use parameterized SQLAlchemy statements to mitigate SQL injection.

💾

Ephemeral vs. Persistent Storage

Cloud containers are stateless and ephemeral. In local development, SQLite stores data in a file. In cloud production, the app connects to a managed database (like AWS RDS or Google Cloud SQL) via the DATABASE_URL environment variable.

⚙️

Environment-Driven Config (12-Factor)

Configuration secrets (such as SECRET_KEY and DATABASE_URL) are injected via environment variables rather than hardcoded in source control, adhering to cloud 12-factor application standards.
